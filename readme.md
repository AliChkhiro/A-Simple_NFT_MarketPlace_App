## A Simple_NFT_MarketPlace_App

###### This is a basic NFT marketplace application. It serves as a personal store where users can browse and view NFTs.

---

## Features

- Browse a collection of NFTs
- View detailed information about each NFT
- Navigate through three main pages:
  - **Home Page** – Display available NFTs
  - **Details Page** – Show information about a selected NFT
  - **Search Page** – Filter and find NFTs easily

---

#### install all dependencies

```js
 npm install
```

#### Run the application

```js
 npm start
```
